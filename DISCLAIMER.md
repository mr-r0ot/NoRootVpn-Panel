## Intended Research Scope

The primary purpose of this project is to **experimentally examine whether technically constrained shared-hosting environments can support a functional VPN-related architecture using PHP and the resources normally available on such hosting plans**.

The project is therefore intended as a technical research and feasibility study involving constraints such as:

* absence of root privileges;
* absence of SSH access;
* restricted process/thread limits;
* limited CPU and memory resources;
* PHP execution restrictions;
* shared web-server environments;
* inability to bind arbitrary public ports;
* and other limitations commonly found on shared hosting.

Any successful deployment should be understood as an **experimental technical result**, not as evidence that such usage is permitted by the hosting provider or lawful in a particular jurisdiction.
