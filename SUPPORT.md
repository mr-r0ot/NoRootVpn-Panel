# Support

## Overview

NoRoot VPN Panel is an experimental research and educational project.

Support is provided on a best-effort basis. No guarantee is made regarding response time, compatibility, availability, or resolution of individual issues.

## Getting Help

For general questions, installation problems, configuration issues, and usage questions, please use the project's GitHub **Issues** section.

Before opening a new issue:

1. Check the `README.md` and available documentation.
2. Search existing Issues for the same problem.
3. Make sure you are using the latest version.
4. Provide enough technical information to reproduce the issue.

## Bug Reports

When reporting a bug, include:

* Operating system and relevant hosting environment.
* PHP version.
* Project version or commit.
* Relevant configuration details, with secrets removed.
* Exact error message.
* Steps to reproduce the problem.
* Expected behavior.
* Actual behavior.
* Relevant logs or screenshots when appropriate.

Do **not** publish passwords, API keys, tokens, private keys, cookies, or other sensitive information.

## Feature Requests

Feature requests and improvements can be submitted through GitHub Issues.

Describe:

* The problem or limitation.
* The proposed functionality.
* Why it would be useful.
* Any relevant technical constraints.

Requests may be rejected when they are outside the project's research scope, incompatible with the architecture, or not practical within restricted shared-hosting environments.

## Security Issues

Do **not** report security vulnerabilities through public GitHub Issues.

Please follow the procedure described in [`SECURITY.md`](SECURITY.md).

## Hosting and Deployment Problems

NoRoot VPN Panel is intended for experimentation in restricted hosting environments.

The project does not guarantee compatibility with any specific hosting provider, control panel, PHP configuration, firewall, operating system, resource limit, or network environment.

Issues caused by provider-specific restrictions, account policies, disabled PHP functions, process limits, blocked network access, or prohibited services may be outside the project's control.

Users are responsible for ensuring that their hosting provider permits their intended use of the software.

## Legal and Policy Matters

Questions regarding legality, hosting-provider policies, telecommunications regulations, or permitted use should not be treated as technical support requests.

See [`DISCLAIMER.md`](DISCLAIMER.md) for the project's full disclaimer.

## Unsupported Requests

The maintainers may decline requests involving:

* Unauthorized access to systems or accounts.
* Bypassing security controls without authorization.
* Malicious use of the software.
* Requests to violate hosting-provider policies.
* Requests requiring infrastructure or permissions unavailable in the user's environment.
* Problems caused entirely by modified or unofficial versions of the project.

## Contribution

Documentation improvements, reproducible bug reports, testing, and code contributions are welcome.

For contribution guidelines, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
